# 공학 쇼츠

"누구나 아는 것 + 눈에 보이는 이상한 점 + 몰랐던 이유"를 30~40초 세로 영상으로 만든다. 예시 완성본 두 편의 대본·프롬프트·사실 확인이 [examples/](examples/)에 있다.

기본값은 **무료 크레딧으로 여러 편** 만드는 쪽이다. 사용자가 바꾸라고 하지 않으면 그대로 따른다.

| 항목 | 기본값 |
|---|---|
| 길이 | 30~40초, 장면 7~8개 |
| 그림체 | 실사 3D 다큐 재현 (모든 장면에 같은 스타일 꼬리) |
| Flow | 동영상 · 프레임 · 9:16 · Omni 1.1 Flash · **360p · 8초 멀티샷**(샷 2~3개) · x1 = 장면당 6크레딧 |
| 하루 한도 | Flow 무료 계정 하루 50크레딧(2026-10 확인) → 8장면 48크레딧 |
| 목소리 | 사용자가 고른 것: 직접 녹음 / 무료 TTS / Typecast 등. 숫자는 한글로 읽힌다 |
| 편집 | Remotion ([templates/EngineeringShort.tsx](templates/EngineeringShort.tsx)). 없으면 편집 앱으로 붙이고 자막 |

## 절대 규칙

1. **크레딧을 쓰기 전에 승인받는다.** "N장면, N크레딧 쓸게요"라고 말하고 사용자가 OK해야 생성한다. 다시 만들 때도 같다.
2. **로그인·결제는 사용자가 한다.** 로그인이 필요하면 사용자에게 부탁하고 기다린다. 비밀번호를 묻거나 입력하지 않는다.
3. **사실은 지어내지 않는다.** 숫자·연도·인명은 공식 자료로 확인하고 출처를 `facts.md`에 남긴다. 자료끼리 다른 숫자는 쓰지 않는다. "왜 그랬는지"는 공식 설명이 있을 때만.
4. **그림·영상 프롬프트에 글자와 숫자를 넣지 않는다.** 숫자는 편집에서 자막·보조 그래픽으로.
5. **실존 인물 얼굴은 그리지 않는다.** 사람은 작게, 뒷모습이나 실루엣.
6. **AI 재현임을 밝힌다.** 화면 구석 "AI 재현 이미지", 설명란에도 한 줄.
7. **남의 사진은 영상에 넣지 않는다.** 실제 생김새는 사진을 보고 특징을 글로 옮긴다.

## 절차 (단계마다 사용자 확인)

```
1 소재     → 후보 3~5개 (반전 한 줄 + 공식 자료 유무)        ← 사용자가 고른다
2 대본     → facts.md(출처) + 장면 7~8개 대사                 ← 사용자가 출처 확인 후 "확정"
3 그림     → 장면마다 세로 그림 1장 (같은 스타일 꼬리)          ← 사용자가 확인, 걸리는 장면만 다시
4 영상     → 1번 장면 멀티샷 테스트(6크레딧) → 승인 → 나머지    ← 크레딧 승인 2번
5 목소리   → 대본 전체를 한 번에 → 1.2배속 → 장면별로 자르기
6 편집     → 샷 나눠 붙이기·자막·보조 그래픽·세 줄 마무리·반복 재생 끝
7 내보내기 → 1080×1920 mp4, 안전 영역·음량 확인
```

### 1 소재
- 기준: 이름만 들어도 아는 것 / 변화가 그림으로 보임 / 공식 자료가 있음. 장소가 아니어도 된다(유적, 조형물, 건물).
- 후보마다 "이상한 점 + 몰랐던 이유 + 공식 자료로 확인 가능?"을 한 줄씩.

### 2 대본 — [references/script.md](references/script.md)
- 첫 문장에 반전 → 사실을 순서대로 → 중간에 "그런데"로 한 번 꺾기 → 세 줄 마무리(지금 가면 보이는 것 / 한 줄 요약 / 이름).
- 대사 두 벌: 목소리용(숫자를 한글로)과 자막용(숫자). 띄어쓰기 단어 수를 맞춘다.

### 3 그림 — [references/style.md](references/style.md)
- 장면 서술 + 스타일 꼬리(토씨 그대로).
- 이미지 생성 도구가 있으면 직접 만든다. 없으면 프롬프트를 주고 사용자가 ChatGPT나 Gemini에서 만들어 `scenes/`에 넣게 한다.

### 4 영상 — [references/flow.md](references/flow.md)
- 브라우저를 조작할 수 있으면(예: Claude in Chrome) Flow를 직접 연다: 설정 확인 → 그림 한꺼번에 업로드 → 장면마다 시작 프레임 + 멀티샷 문장 → 생성 → 프로젝트 다운로드.
- 브라우저 조작이 안 되면 문장을 장면별로 주고 사람이 누르게 안내한다.

### 5 목소리
- **대본 전체를 한 번에** 생성한다. 장면마다 따로 만들면 문장마다 억양이 새로 시작해 어색하다.
- **1.2배속.** 원래 속도는 쇼츠에서 지루하다.
- 단어 타임스탬프로 장면을 자른다. 크기는 -16 LUFS.
- 직접 녹음이면 대본을 한 번에 읽어 녹음하고 장면 경계에서 자른다.

### 6 편집 — [references/edit.md](references/edit.md)
- 장면 길이를 멀티샷의 샷 수로 나눠 각 샷 시작부터 이어 붙인다(샷당 최소 0.8초).
- 자막 한 줄씩(y≈1267), 첫 화면 질문 제목, 상시 "AI 재현 이미지".
- 보조 그래픽: 시대가 이어지면 상단 연표, 숫자는 큰 라벨, 변화는 "A → B" 알약.
- 클립 소리는 클립마다 재서 약 -36 LUFS로. 끝은 **페이드아웃 없이** 첫 장면 클립으로 닫는다.

### 7 내보내기
- 1080×1920. 글자는 x 140~940, y 260~1500 안. 3초 간격 프레임에 안전 영역 테두리를 그려 확인.
- 전체 디코딩, 음량(-14~-18 LUFS) 확인.

## 보고
단계마다 한두 줄로 한 일과 다음 일. 크레딧 쓰기 전에는 예상량. 문제를 발견하면 장면 번호와 증상을 숨기지 않는다.
