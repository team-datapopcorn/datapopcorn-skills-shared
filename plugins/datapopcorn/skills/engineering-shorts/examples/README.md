# 예시 두 편

| 예시 | 길이 | Flow | 특징 |
|---|---|---|---|
| `pyramid/` 피라미드는 원래 하얗게 빛났다 | 약 30초 | 360p 8초 멀티샷 × 8 = 48크레딧 | 기본 방식. 장면마다 샷 2~3개 → 컷 20개 안팎 |
| `yeouido/` 여의도는 원래 비행장이었다 | 약 42초 | 360p 6초 단일 샷 × 8 = 40크레딧 | 단일 샷이라 컷이 8개로 느슨했다 → 멀티샷으로 바꾼 계기 |

파일
- `image-prompts.json` 장면 그림 프롬프트(스타일 꼬리 포함)
- `multishot-prompts.json` / `motion-prompts.md` Flow 문장
- `vo-script.json` 목소리용 대사(숫자 한글) + 자막 줄(숫자)
- `facts.md` 쓴 사실·출처·쓰지 않은 것

만들면서 고친 것 (모두 SKILL.md 규칙이 됨)
1. 장면별로 만든 목소리가 어색함 → 대본 전체를 한 번에 생성해 자르기
2. 배속이 없으면 지루함 → 1.2배속
3. 소리가 들쑥날쑥 → 목소리 -16 LUFS, 클립 소리는 클립마다 -36 LUFS로
4. 연표 양 끝 글자가 잘려 보임 → 상자 여백 넓히고 점은 같은 간격
5. 반복 재생 → 끝 페이드아웃 없이 첫 장면 클립으로 닫기
6. 컷이 적어 느슨함 → 멀티샷
