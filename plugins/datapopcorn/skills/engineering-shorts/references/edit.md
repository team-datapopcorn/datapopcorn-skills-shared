# 편집 (Remotion)

템플릿: `templates/EngineeringShort.tsx` (피라미드 예시, 멀티샷 샷 나누기 포함). Remotion 프로젝트가 없으면 먼저 만든다(`npx create-video@latest`).

## 파일 배치
- `public/<프로젝트>/c1.mp4 …` 장면 클립(360×640, 6초, 24fps)
- `public/<프로젝트>/scene-0.wav …` 장면별 목소리(한 번에 생성한 걸 자른 것, -16 LUFS)
- `vo-timeline.ts` 장면 id·프레임·자막 그룹(startMs/endMs)

## 화면 규칙
- 1080×1920, 30fps. 글자는 x 140~940, y 260~1500.
- 자막: Pretendard 800, 70px, 흰 글씨 8방향 검은 외곽선, top 1267, 한 줄.
- 첫 장면: 질문 제목 두 줄(키워드 노랑 #F8E663), top 340.
- 상시: 왼쪽 위 "AI 재현 이미지"(28px, 반투명 검정 바탕), top 270.
- 연표: 상단 상자 x 150~930, 점은 같은 간격(연도 간격이 다르면 겹친다), 현재 해 노랑·크게.
- 라벨: 노란 큰 글씨 + 흰 보조 글씨. 알약: "A → B".

## 소리
- 클립 소리는 클립마다 LUFS를 재서 약 -36 LUFS가 되도록 볼륨 계산(최대 1). 군중(-17) → 0.11, 거의 무음(-44) → 1.
- 목소리는 public 파일 자체를 -16 LUFS로.

## 길이
- 장면 길이 = 목소리 길이. 6초 클립보다 길면 `playbackRate = (180 - startFrom) / 장면 프레임`.
- 마지막: 페이드아웃 없이 첫 장면 클립으로 닫고 여유 12프레임.

## 확인
- 렌더 전 Studio에서 장면마다 확인(사용자에게 링크).
- 렌더 후: `ffmpeg -i out.mp4 -f null -`(디코딩), ebur128(음량), 3초 간격 + `drawbox=x=0:y=260:w=940:h=1240` 시트.

## vo-timeline.ts 만들기
- 대본 전체를 한 번에 TTS로 만들고 단어 타임스탬프를 받는다(Typecast·ElevenLabs 등 타임스탬프를 주는 도구).
- 1.2배속 → -16 LUFS → 장면 경계(다음 장면 첫 단어 0.06초 앞)로 잘라 `public/<폴더>/scene-N.wav`.
- 장면마다 `frames = ceil(길이×30)`, 자막 그룹은 단어 수로 나눠 startMs/endMs.
- 타임스탬프가 없는 목소리(직접 녹음)는 장면별로 녹음하고, 자막 줄은 길이에 비례해 나눈다.
