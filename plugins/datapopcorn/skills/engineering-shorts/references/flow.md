# Google Flow (2026-10-16 화면 기준)

## 설정

입력칸 오른쪽 설정 칩 → **동영상 · 프레임 · 9:16 · Omni 1.1 Flash · 360p · 6초 · x1** → "생성 시 5크레딧이 사용됩니다".

- 계정 기본값이 **이미지 모드(Nano Banana)**일 수 있다. 그러면 칩에 "동영상 ·"이 없다. 칩을 눌러 "동영상"부터 고른다.
- 720p는 같은 6초에 10크레딧. 사용자가 원할 때만.
- 무료 계정도 하루 50크레딧(2026-10 확인). 모자라면 다음 날 이어서.

## 브라우저로 조작할 때 (Claude in Chrome 등)

1. 사용자가 평소 쓰는 크롬에서 Flow가 로그인돼 있는지 확인. 안 돼 있으면 사용자에게 로그인을 부탁한다.
2. 새 프로젝트 → 설정 확인(위).
3. **시작** 칸 → 프레임 이미지 선택 창 → **미디어 업로드**로 그림을 한꺼번에 올린다.
   - 업로드 버튼은 숨은 파일 입력을 만든다. 파일 선택 창을 띄우지 말고, `HTMLInputElement.prototype.click`을 잠깐 바꿔 입력을 DOM에 붙인 뒤 파일 업로드 도구로 넣는다.
4. 장면마다: 시작 칸 → 검색칸에 파일 이름 → 그림 선택 → **프롬프트에 추가** → 입력칸에 움직임 문장 → 화살표.
   - 앞 장면이 만들어지는 동안 다음 장면을 넣어도 된다.
5. 완료되면 영상 위 **⋮ → 다운로드 → 360p**. 파일 이름이 장면 내용으로 붙는다(예: `Biplane_takes_off_from_runway_….mp4`). 장면 번호로 이름을 바꿔 프로젝트 폴더에 둔다.
6. 1초·3초·5.5초 프레임 시트로 확인. 녹아내림·글자·엉뚱한 물체가 있으면 그 장면만 다시(크레딧 승인).

## 카메라는 하나만

- `Static camera.` — 사람·비행기만 움직일 때
- `Slow push-in toward …` — 대부분
- `Slow tilt up …` — 높은 벽·건물

움직임을 여러 개 넣으면 그림이 녹아내린다. 한 장면에 움직임 한두 개.

## 막힐 때

- 99%에서 멈추고 사라짐 → 같은 그림·같은 문장으로 다시.
- 쿠키 안내가 입력칸을 가림 → "나중에"(필수 외 거절).
- 오른쪽 아래 ✦ 표시는 Flow 표시다. 지우지 않는다(세로 영상 아래 데드존이라 UI에 가려진다).

## 멀티샷 (2026-10-16 피라미드 편에서 확인) — 기본 권장

컷이 적으면 느슨하다. **8초 영상 하나에 샷 2~3개**를 넣는다. 360p 8초 = 6크레딧, 8장면이면 48크레딧(무료 50 안).

```text
Multi-shot video with three shots and hard cuts between them. Shot 1 (0-3s): starting from the start frame, [카메라와 움직임]. Shot 2 (3-6s): cut to [같은 장면의 다른 각도·확대]. Shot 3 (6-8s): cut to [넓은 뷰 등]. Keep the same [피사체], era and lighting in every shot. Photorealistic 3D documentary reconstruction. No text, no letters, no numbers, no logos.
```

- 첫 샷은 시작 그림에서 출발하고, 뒤 샷은 문장만으로 만든다. 그림체가 세 샷 모두 일관됐다
- 컷은 적은 초에 거의 정확히 생긴다(3.0초, 5.9초). `ffmpeg -vf "select='gt(scene,0.3)',showinfo"`로 재서 편집에 쓴다. 부드러운 전환은 검출이 안 되니 적은 초를 그대로 쓴다
- 편집에서는 장면 길이(목소리)를 샷 수로 나눠 각 샷의 시작부터 이어 붙인다(샷당 최소 0.8초)
- 장면 하나를 먼저 테스트하고 나머지를 진행한다

## 회수
- 여러 개면 ⋮(오른쪽 위) → **프로젝트 다운로드**로 zip 한 번에. zip 안 파일 이름이 장면 내용으로 붙는다
- zip 이름에 한글이 있으면 `unzip`이 실패할 수 있다 → 파이썬 zipfile로 푼다
- 마지막 장면 직후 "크레딧 부족" 알림이 떠도 생성은 됐을 수 있다. 목록에서 확인한다
