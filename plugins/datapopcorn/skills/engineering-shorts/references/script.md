# 대본

## 구조 (30~40초, 장면 7~8개)

1. **반전 먼저**: "국회의사당 앞 이 넓은 공원, 원래는 비행기가 뜨고 내리던 비행장이었습니다."
2. **사실을 순서대로**: 시간 순서(연도) 또는 숫자 비교(크기·거리). 한 장면에 한 문장.
3. **"그런데"로 한 번 꺾기**: "그런데 이 공항, 가장 큰 골칫거리는 물이었습니다."
4. **결과**: 그래서 무엇이 바뀌었나.
5. **세 줄로 닫기**: 지금 가면 보이는 것 / 한 줄 요약 / 장소 이름(크게).

새 정보 하나로 끝내면 급하게 끝난 느낌이 든다. 세 줄 마무리는 반드시 넣는다.

## 사실 확인

- 숫자·연도·인명마다 출처 링크. `facts.md`에 "쓴 것 / 쓰지 않은 것(이유)"을 나눠 적는다.
- 자료끼리 다르면 쓰지 않는다. 대사에서 연도를 빼고 사건만 말한다("김포로 옮겨 가고").
- "최초·최고" 같은 발표 측 주장은 표시만 하고 단정하지 않는다.
- 원인과 결과를 지어내지 않는다. "덕분에", "그래서"는 자료에 있을 때만.
- 사용자에게 출처를 직접 눌러 보라고 안내한다.

## 두 벌의 대사

| 목소리용 (vo-script) | 자막용 |
|---|---|
| 천구백십육년, 한강 모래밭에 육백미터짜리 활주로가 깔립니다. | 1916년, 한강 모래밭에 600m짜리 활주로가 깔립니다. |

띄어쓰기 단어 수가 같아야 한다("육백 미터짜리"처럼 띄우면 한 단어가 늘어난다). 자막은 단어 타임스탬프로 줄을 나눈다. 한 화면 자막은 한 줄(15자 안팎)로 나눠 적는다.
