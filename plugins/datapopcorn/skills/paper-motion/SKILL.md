# 종이 브랜드 모션

사용자가 요청한 문구와 색을 포함된 예제에 적용하여 새 작업 폴더를 만든다. 예제 원본은 유지한다. 모호한 디자인 선택은 예제 기본값으로 시작하고 검토 화면을 보여준다.

```bash
python3 <이-스킬-경로>/scripts/create.py --output <새-작업-폴더>
```

에이전트가 실제 스킬 경로로 바꿔 실행한다. Python이 없으면 `assets/paper.html`을 새 폴더의 index.html로 복사한다. 기존 파일을 덮어쓰지 않는다.

## 수정

화면의 브랜드명·슬로건 입력으로 먼저 검토하고, 영구 기본값과 색은 파일 상단 CONFIG의 실제 키를 읽어 수정한다. 문자열은 JS/HTML 문법에 맞게 이스케이프한다.

정적인 제목 페이드로 대체하지 말고 예제의 카메라 공전·눈·접힘 축과 그림자를 유지한다. 변경은 새 파일/버전으로 남기고 사용자가 승인한 이전 결과를 보존한다. 이번 결과의 색·문구·수정 요청은 작업 폴더에 짧게 기록해 다음 제작에 재사용한다.

## 보기와 저장

작업 폴더에서 `python3 -m http.server 8000 --bind 127.0.0.1`로 로컬 미리보기를 열 수 있다. 이미 쓰는 포트라면 빈 포트를 사용한다. 서버를 열었다는 이유로 인터넷에 배포하지 않는다.

Chrome에서 재생, 진행바, 입력 변경, WebM 저장을 확인한다. 녹화 중에는 탭을 보이는 상태로 유지한다. WebM 저장은 720×1280이며 브라우저 상태에 따라 실제 길이·프레임 간격이 달라질 수 있다. 파일의 존재만으로 성공이라고 하지 않는다. 처음·중간·끝 화면과 실제 재생을 확인한다.

MP4가 필요하고 FFmpeg가 설치돼 있으면 다음처럼 변환한다. 새 출력 경로를 써서 기존 파일을 보존한다.

```bash
ffmpeg -i input.webm -an -r 30 -c:v libx264 -pix_fmt yuv420p -movflags +faststart output.mp4
```

## 전달과 한계

HTML 경로, 미리보기 주소, 실제 저장한 영상, 변경 내용을 전달한다. 브라우저 검수가 불가능하면 확인하지 못한 항목을 명시한다. 설치·생성·녹화 실패를 숨기지 않는다. 공개 게시와 유료 서비스 사용은 이 스킬 실행만으로 승인되지 않는다.

예제 원본은 DataPopcorn이 Claude Sonnet 5.5로 제작했고, 배포본은 거절된 구형 브랜드 장면을 제거한 것이다. 이 스킬이 특정 모델을 자동 선택하지 않는다. 다른 모델이 수정했다면 그 수정까지 Sonnet 결과라고 부르지 않는다.

3D 예제는 Three.js CDN, 예제 서체는 Google Fonts 인터넷 연결을 사용한다. 외부 사진·생성 영상·Remotion은 필요 없다. macOS Chrome에서 원본을 검토했으며 Windows/Safari는 직접 검증하지 않았다. 사운드는 포함하지 않는다.
