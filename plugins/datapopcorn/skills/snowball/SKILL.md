# 도시 스노글로브

사용자가 원하는 지역의 스노글로브를 새 작업 폴더에 만든다. 서울·파리·도쿄·뉴욕은 기본 예제이며 선택 가능한 지역의 제한이 아니다. 예제 원본은 유지한다. 모호한 디자인 선택은 예제 기본값으로 시작하고 검토 화면을 보여준다.

```bash
python3 <이-스킬-경로>/scripts/create.py --output <새-작업-폴더>
```

에이전트가 실제 스킬 경로로 바꿔 실행한다. Python이 없으면 `assets/worlds.html`을 새 폴더의 index.html로 복사한다. 기존 파일을 덮어쓰지 않는다.

## 지역을 장면으로 만들기

1. 지역을 지정했다면 그대로 시작한다. 같은 이름의 지역이 여럿이고 문맥으로 구분할 수 없을 때만 나라나 시·도를 묻는다. 지역을 지정하지 않았다면 원하는 지역을 묻거나 기본 네 도시를 안내한다.
2. 기본 네 도시를 요청하면 기존 모델을 재사용한다. 그 외 지역은 공식 관광청·지자체·랜드마크 공식 자료에서 형태와 지역을 확인한다. 대표 랜드마크 1–2개와 바다·산·거리 등 지형 특징을 선정한다. 사용자가 지정한 장소를 우선한다. 자료를 열 수 없다면 추측을 사실처럼 쓰지 말고 사용자가 준 참고 사진이나 확인 가능한 특징으로 범위를 줄인다.
3. `references/custom-region.md`를 읽고 작업 사본에 지역 전용 builder를 만든다. 각인만 교체하거나 다른 도시의 건물을 그대로 둔 채 새 지역이라고 부르지 않는다. 사진 복제보다 작은 구슬에서 알아볼 수 있는 실루엣과 배치를 우선한다.
4. 지역 버튼, 초기 선택, 각인 기본값, 영상 파일명이 같은 지역을 가리키게 한다. 기본 도시도 계속 선택 가능하게 유지한다. 지역 이름·입력 문구는 JS/HTML 문법에 맞게 이스케이프한다.
5. 눈·구슬·카메라 공전·그림자를 유지하며 실제 브라우저에서 처음·중간·끝을 본다. 랜드마크가 구슬 밖으로 튀어나오거나 가려지지 않는지, 지역 전환 후 돌아와도 정상인지 확인한다. 실패하면 수정하고 다시 확인한다. 검수 도구가 없으면 실행 검증 전이라고 표시한다.

작업 폴더의 `REGION.md`에 지역, 참고 URL, 선택한 특징, 단순화한 부분, 수정 모델, 검수 결과를 기록한다. 결과는 지역을 재해석한 미니어처이며 정확한 축척 지도라고 주장하지 않는다. 다른 모델이 새 지역을 만들었다면 Sonnet이 그 지역까지 만들었다고 말하지 않는다.

예: “부산, 광안대교와 바다, 각인은 BUSAN” → 해안과 현수교의 특징을 확인해 새 지형·교량을 만든다. 서울 장면의 각인만 BUSAN으로 바꾸는 것은 완료가 아니다.

## 보기와 저장

작업 폴더에서 `python3 -m http.server 8000 --bind 127.0.0.1`로 로컬 미리보기를 열 수 있다. 이미 쓰는 포트라면 빈 포트를 사용한다. 서버를 열었다는 이유로 인터넷에 배포하지 않는다.

Chrome에서 재생, 진행바, 입력 변경, WebM 저장을 확인한다. 녹화 중에는 탭을 보이는 상태로 유지한다. WebM 저장은 720×1280이며 브라우저 상태에 따라 실제 길이·프레임 간격이 달라질 수 있다. 파일의 존재만으로 성공이라고 하지 않는다. 처음·중간·끝 화면과 실제 재생을 확인한다.

MP4가 필요하고 FFmpeg가 설치돼 있으면 다음처럼 변환한다. 새 출력 경로를 써서 기존 파일을 보존한다.

```bash
ffmpeg -i input.webm -an -r 30 -c:v libx264 -pix_fmt yuv420p -movflags +faststart output.mp4
```

## 전달과 한계

HTML 경로, 미리보기 주소, 실제 저장한 영상, 변경 내용을 전달한다. 브라우저 검수가 불가능하면 확인하지 못한 항목을 명시한다. 설치·생성·녹화 실패를 숨기지 않는다. 공개 게시와 유료 서비스 사용은 이 스킬 실행만으로 승인되지 않는다.

예제 원본은 DataPopcorn이 Claude Sonnet 5.5로 제작했고, 배포본은 거절된 구형 브랜드 장면을 제거한 것이다. 이 스킬이 특정 모델을 자동 선택하지 않는다. 다른 모델이 수정했다면 그 수정까지 Sonnet 결과라고 부르지 않는다.

3D 예제는 Three.js CDN, 예제 서체는 Google Fonts 인터넷 연결을 사용한다. 외부 사진·생성 영상·Remotion은 필요 없다. macOS Chrome에서 원본을 검토했으며 Windows/Safari는 직접 검증하지 않았다. 사운드는 포함하지 않는다.
